# Fan Map 기능 명세

> 기준: 현재 PoC 구현 (코드 기준)  
> 서비스명: **Fan Map**  
> 한 줄 소개: 응원·방문 장소를 지도에서 찾고, 다녀온 경험을 공유하는 지도 서비스

스포츠 경기를 함께 볼 수 있는 음식점·술집을 지도에서 찾고, 실제 방문 경험을 남기고 확인할 수 있습니다.  
대상 종목: 야구, 축구, 농구, 배구, e스포츠, 기타

---

## 1. 화면 구성

### 1.1 지도 홈 (`/`)

| 영역 | 설명 |
|------|------|
| 지도 | 네이버 지도. 장소 마커, 팬·줌 |
| 검색 | 등록된 전체 장소에서 가게명·팀·지역 검색. 결과 없으면 **다녀왔어요** CTA |
| 필터 | 전체 / 이벤트 / 종목 / 즐겨찾기 |
| 장소 목록 | 평소: 이 지역 / 검색 중: 등록 전체 결과 (+ 칩 필터) |
| 장소 상세 | 정보·방문 경험·액션 |
| 이 지역 랭킹 | 현재 영역 Top 7 |
| 컨트롤 | 이 지역 검색, 현재 위치, 랭킹(트로피) |

**반응형**

- **모바일 (`md` 미만)**: 지도 풀폭 + 상단 검색·필터 + 하단 장소 시트
- **태블릿·중형 (`md`~`xl`)**: 좌측 목록 + 지도. 랭킹은 트로피 → 다이얼로그
- **넓은 PC (`xl` 이상)**: 지도 우측 상단 랭킹 패널 고정

### 1.2 공통 헤더

로고 **Fan Map** · **서비스 모드** (스포츠 활성, 아티스트·브랜드·문화는 준비 중) · **다녀왔어요** · 테마 전환 · 계정 · 메뉴

### 1.3 계정·고객지원

| 경로 | 화면 |
|------|------|
| `/login` | 로그인 |
| `/register` | 회원가입 |
| `/forgot-password` | 비밀번호 찾기 |
| `/mypage` | 마이페이지 |
| `/mypage/reports` | 방문 기록 |
| `/mypage/favorites` | 즐겨찾기 |
| `/mypage/profile` | 내 정보 관리 |
| `/mypage/settings` | 설정 |
| `/mypage/withdraw` | 회원 탈퇴 |
| `/notices` | 공지사항 |
| `/help` | 자주 묻는 질문 |
| `/terms` | 이용약관 |
| `/privacy` | 개인정보 처리방침 |

## 2. 지도·장소 탐색

### 2.1 지도

- 기본 중심: 잠실 인근 (시드)
- 최초 진입 시 현재 위치 요청 → 실패 시 기본 중심
- **이 지역 검색** / **현재 위치로 이동**
- 검색어 없을 때: 영역 밖 장소는 목록·마커 제외 (랭킹도 이 지역)

### 2.2 검색·필터

- 검색: 등록된 **전체** 장소에서 상호·주소·카테고리·종목·팀명·약칭
- 검색 결과가 화면 밖이면 첫 결과로 지도 이동
- 검색 0건: **다녀왔어요** CTA로 제보 유도
- 필터(칩): 목록 기준 집합 위에 종목·이벤트·즐겨찾기 적용
- 평소 목록 기준: 이 지역 / 검색 중: 전체 등록 장소

### 2.3 목록·상세·마커

- 목록: 커버, 상호, 주소, 태그, **핫**, 방문 요약, 즐겨찾기
- **핫**: 오늘 방문 &gt; 0 또는 최근 14일 방문 ≥ 2 (`createdAt` 기준)
- 상세: 기본 정보, 오늘/최근 방문·방문 경험 수, 이벤트, 갤러리, 외부 지도 링크, 종목·태그, **최근 방문** 목록
- 액션: 다녀왔어요, 공유, 즐겨찾기, 목록으로
- 마커: 현재 목록(`displayPlaces`) 기준, 종목 색·아이콘

## 3. 방문 경험

### 3.1 작성

1. **다녀왔어요** / 상세 CTA / `/?report=1` (비로그인 → 로그인)
2. 상호명 검색 (네이버 Local Search)
3. 폼 제출 → **남기기**

| 항목 | 규칙 |
|------|------|
| 사진 | 최대 5장 (로컬 Base64) |
| 태그 | 시설·분위기·음식·시야·기타 |
| 종목 · 팀 | 1개 이상 세트, 종목당 팀 다중, 종목 중복 불가 |
| 방문 일시 | 필수 (분 단위) |
| 후기 | 10~1,000자 |

### 3.2 목록·정렬·일시 표기

- 정렬: **방문 일시(`watchedAt`) 최신순** (동률 시 작성 시각)
- 카드 상대 시각: `watchedAt` 기준
  - 10일 미만: `방금` / `N분 전` / `N시간 전` / `N일 전`
  - 10일 이상: `yyyy-mm-dd hh:mm`
- 축약 표기만 PC 호버·모바일 탭으로 절대 일시 팝오버
- 오늘/최근 방문·랭킹 HOT/급상승 집계: **작성 시각(`createdAt`)**

### 3.3 수정·삭제·신고·좋아요

- 본인: 수정 / 삭제
- 타인: 신고 (PoC 토스트만)
- 좋아요: **비로그인 가능** (계정 id 또는 브라우저 게스트 id, 글당 1회)

### 3.4 마이페이지 · 방문 기록

내가 작성한 글 모아보기·삭제 (`watchedAt` 최신순)

## 4. 이 지역 랭킹

현재 영역 장소 Top 7. 목록에는 **상호명만** 표시.

| 탭 | 기준 (`createdAt`) |
|----|------|
| **오늘 HOT** | 오늘 방문×1000 + 최근 14일 방문 |
| **급상승** | 최근 7일 vs 직전 7일 증가 |
| **팬 추천** | 좋아요 합×10 + 방문글 수 |

- `xl` 이상: 우측 패널 / 미만: 트로피 → 다이얼로그

---

## 5. 계정·즐겨찾기

- 로그인: 카카오·네이버·Google Mock + 이메일
- 로그인 필요: 제보 작성·수정, 즐겨찾기, 신고 (좋아요 제외)
- 즐겨찾기: 계정별 localStorage (`fan-map:favorites:{userId}`)

## 6. 데이터·연동 (PoC)

| 구분 | 상태 |
|------|------|
| 네이버 지도 | 실연동 |
| Local Search | 실연동 (서버 프록시) |
| 장소·방문 경험 | Mock 시드 + localStorage |
| 즐겨찾기·좋아요·설정 | localStorage |
| 인증·알림·약관·공지·신고 | Mock / UI |
| 사진 | Base64 (서버 업로드 없음) |
| 기기 간 동기화 | 없음 |

## 7. 기능 흐름

```
지도 홈
 ├─ 검색 · 필터 · 이 지역 검색 · 현위치
 ├─ 목록 ↔ 상세 ↔ 마커
 ├─ 이 지역 랭킹 (HOT / 급상승 / 팬 추천)
 └─ 다녀왔어요 → 상호 검색 → 방문 경험
                    ├─ 사진 · 태그 · 종목/팀 · 일시 · 후기
                    └─ 수정 · 삭제 · 신고 · 좋아요

계정
 ├─ 로그인 / 회원가입 (Mock)
 └─ 마이페이지 · 방문 기록 · 즐겨찾기 · 설정 · 탈퇴 · 고객지원
```
